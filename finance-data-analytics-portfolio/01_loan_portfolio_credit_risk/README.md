# Loan Portfolio & Credit Risk Analysis

**Tools:** Python, pandas, matplotlib

## Objective
Explore loan applications, approval patterns, estimated repayments, and late-payment flags by loan type.

## Run
```bash
python -m pip install -r requirements.txt
python 01_loan_portfolio_credit_risk/analysis.py
```

The script creates a synthetic sample portfolio, prints summary metrics, saves a loan-type summary CSV, and creates a chart. Data is generated for educational use only and does not represent any lender.

## Skills demonstrated
- Data generation and cleaning
- Grouped aggregations and KPI calculation
- CSV export and visualization
- Interpreting lending metrics cautiously
