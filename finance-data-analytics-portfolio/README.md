# Finance & Data Analytics Portfolio

Two beginner portfolio projects for financial-services analytics, built with Python and synthetic data.

## Projects
1. **Loan Portfolio & Credit Risk Analysis** — descriptive analytics and visualizations for a synthetic loan portfolio.
2. **Customer Repayment & Delinquency Prediction** — a baseline machine-learning classifier with evaluation metrics.

## Important data note
All records are synthetic and generated for learning. They are not real customer data and are not affiliated with or representative of Bajaj Finance or any lender. The model is educational only and must not be used to make real credit decisions.

## Requirements
Python 3.10+

Install dependencies:
```bash
python -m pip install -r requirements.txt
```

Run projects from this folder:
```bash
python 01_loan_portfolio_credit_risk/analysis.py
python 02_customer_delinquency_prediction/train_model.py
```

See each project README for workflow and interpretation.
